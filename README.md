# Placement Prediction using Machine Learning

A simple Machine Learning project to predict whether a student will get placed based on academic and skill-related features.

## Models Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Random Forest Classifier

## Results

| Model               | Accuracy | Cross Validation |
| ------------------- | :------: | :--------------: |
| Logistic Regression |    90%   |      90.12%      |
| KNN                 |    95%   |      94.26%      |
| Random Forest       | **100%** |    **99.99%**    |

**Best Model:** Random Forest Classifier

## Features

* Data Preprocessing Pipeline
* Exploratory Data Analysis (EDA)
* Model Comparison

* Prediction Script
